# ADR-0005：保留原生窗口装饰，采用一体化工作区外壳

- 状态：Superseded by ADR-0006（2026-11-06）
- 日期：2026-11-06
- 决策者：项目负责人（用户）与主开发助手
- 相关文档：`docs/design/UI_REDESIGN_PHASE_3_5.md`、`docs/design/DESIGN_SYSTEM.md`、`docs/design/UI_AUDIT.md`
- 上游决策：ADR-0001（Tauri 2 本地优先架构）

## 背景

Phase 3 的 Windows 界面存在明显的顶部断层：

1. 原生标题栏；
2. 应用级顶栏（项目名、Git 状态、主题切换）；
3. 页面标题与内容。

三层横向分割、不同背景和边框高度，使应用看起来像“网页套在桌面壳里”，而不是一个桌面开发工具。

用户要求评估 Tauri 2 的窗口自定义能力，优先解决顶部断层；但明确要求不能为了视觉效果牺牲原生窗口行为。

## 决策

### 1. 保留原生 Windows 窗口装饰

不启用 `decorations: false`，不实现自定义标题栏。原生标题栏负责：

- 拖动窗口；
- 双击标题栏最大化/还原；
- 最小化、最大化、还原、关闭；
- 窗口边缘缩放；
- Windows 11 Snap Layouts / Snap 操作；
- 多显示器与系统 DPI 行为；
- 窗口焦点与辅助功能。

### 2. 移除应用级顶栏，改为一体化工作区

- 删除 Phase 3 的 56px 应用顶栏。
- 左侧固定 **240px** 工作区侧栏；品牌、当前项目、Git 上下文、导航与主题均在侧栏内。
- 主内容顶端直接是页面上下文行（PageHeader，最小高度 48px），与侧栏品牌行对齐。
- 页面标题、项目上下文、操作与内容共享同一工作区背景；不再出现第三条全宽横栏。
- 当前项目切换、分支/HEAD/dirty 与当前项目详情入口集中在侧栏的一个紧凑上下文块中。

### 3. 原生标题栏主题同步

- 使用窗口级 `plugin:window|set_theme` 命令（`label: main`）在浅色/深色/跟随系统间同步原生窗口主题。
- 仅增加 `core:window:allow-set-theme` 权限；不开放 Shell、文件系统、任意窗口控制或其他窗口权限。
- 主题同步失败只影响标题栏配色，不回滚页面主题。

### 4. 不实现自定义窗口控制

未采用：

- `decorations: false` + `data-tauri-drag-region`；
- 自定义最小化/最大化/关闭按钮；
- 自定义边缘缩放手柄；
- 自定义 Snap Layouts 模拟。

原因：在 Windows 上完整复刻原生缩放、Snap、DPI 与多显示器行为需要额外平台代码，且难以在本机单显示器/单 DPI 环境下充分验证；本轮优先保证稳定性与用户既有操作习惯。

## 备选方案与取舍

| 备选 | 未采用原因 |
|---|---|
| 保留 Phase 3 的三层顶栏，仅换色 | 不能解决用户明确指出的窗口视觉断层。 |
| 隐藏原生标题栏 + 自定义标题栏 | 需自行处理拖动、双击、缩放、Snap、DPI、多显示器、焦点与可访问性；本轮无法充分验证，退化风险高。 |
| 使用 Tauri 的 overlay title bar 样式 | 该能力主要面向 macOS；Windows 端仍以装饰/无装饰为主，不能可靠替代原生控制。 |
| 保留原生标题栏，移除应用顶栏 | 采用。保留全部原生行为；通过侧栏 + 页面上下文行实现一体化。 |
| 让侧栏与主内容共用滚动 | 会导致导航随长页面滚走；采用独立主滚动区。 |

## 后果

**正面：**

- 原生拖动、双击、最小化/最大化/还原、边缘缩放、Snap Layouts 与 DPI 行为完整保留。
- 顶部从三层降为“原生标题栏 + 单一工作区”，视觉断层显著减少。
- 侧栏成为稳定的项目上下文与导航中心；主内容只保留页面级标题。
- 仅新增一个窄范围主题权限，安全面变化有限。
- 原生标题栏颜色随应用主题切换；深浅模式完整。

**负面 / 风险：**

- 原生标题栏仍是一条 OS 管理的横条，无法做到 Obsidian 式的完全客户区绘制。
- 自定义标题栏的视觉自由度未使用；如果未来需要，必须新增 ADR，并完成拖动、双击、最小化/最大化/关闭、边缘缩放、Snap、多显示器、DPI、焦点与可访问性测试。
- 原生标题栏的精确外观受 Windows 主题和系统版本影响。
- 本轮只验证了单显示器、100%/150% 缩放环境；多显示器与其它 DPI 仍需后续实机验证。

## 回滚

若未来切换为自定义标题栏，必须：

1. 新增 ADR 说明原因、视觉收益与平台风险；
2. 保留 `core:window:allow-set-theme` 或替换为经过审查的窗口权限；
3. 完成原生行为回归清单；
4. 保留当前原生标题栏实现作为可回滚路径，不删除用户数据或改变业务语义。
